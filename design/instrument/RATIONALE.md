# Instrument 精密仪器 — 设计说明（M49）

> 走查入口：`design/instrument/index.html`（单文件，浏览器直接打开）。
> 控制台可调：主题（亮/暗/电子墨水）、行宽（默认 480px）、语言（中/英）、状态（空态→归档九态）、批注、灰度模拟。
> URL 参数直达任意组合：`?theme=eink&state=review&lang=en&measure=720&annotate=on&gray=on`。
> 从「满态」起签名流程可真实操作：选中正文 → 创建编辑点 → ⇧⌘D 委派 → 确认 → 逐点回看（⌘↵ 接受 / ⌘⌫ 拒绝 / ⌘J 跳正文 / ⌘[ ⌘] 切换）→ 全部裁决后显式归档（横幅「归档」按钮或 ⌘K）。

## 一、命题：工具工艺即美

一台精密仪器（千分尺、机械表盘、相机对焦环）的美不来自装饰，而来自四件事：**读数清晰、反馈精确、状态可辨、无一物多余**。本方向把这四件事转译为 Lumir 的界面语言：

- **读数清晰** → 底部状态栏是仪表面板：文件路径 / 字数 / 编辑点计数 / agent 状态 / 行宽，全部等宽 tabular 数字、格子分隔、左到右读。选中文字时即时出现「段 4 · 选 22 字」读数，创建编辑点或状态切换后即刻清零；无任务时编辑点与 agent 两格读数归零为「—」（指针归零，不是隐藏格子）。这是 v1/v2 都没有的签名元素。
- **反馈精确** → 一切可交互面走 Geist 功能态三级 token（背景与边框各分 default/hover/active），hover 反馈统一 150ms；面板滑入 220ms；动画只用 transition/transform/opacity，天然可中断。
- **状态可辨** → agent 状态按 calmtech 分级谱落地：light=正文点状锚点、tone=顶部完成横幅、shout=回看卡（header 承载「为什么改」）、popup 仅文件冲突。底部读数行始终有一格报告 agent 当前状态。
- **无一物多余** → 默认阅读态只有正文 + 退后的导航 + 读数行；委派按钮只在有开放编辑点时出现在工具栏；Context Surface 默认隐藏、随状态从右滑入、归档后向右收回。

**密度自检**：精密不等于堆细节。本稿的密度全部服务于「一眼读出系统状态」（仪表盘），正文的安静没有被破坏——阅读态截图（`state=full`）与 v2 一样干净，多出来的只有底部 28px 读数行。

## 三、关键决策与数值依据

### 3.1 三主题是同一骨架的三套约束

- **亮**：纯白正文面（`--bg:#fff`）+ 导航 `#f4f5f6`（退两色阶）。强调色预算两枚：蓝主强调 `#3b5bdb` + 青 agent 语义色 `#0c9488` + 红仅用于破坏性（冲突圆点、删除线）。
- **暗**：石墨 `#1a1c20` 而非纯黑——中性灰底是环境光适配，不是氛围切换；所有层级与亮主题同构，只换 token 值。
- **电子墨水**：纯黑纯白、禁灰阶、无阴影无透明无动画（全局 `transition/animation/box-shadow:none`）。弱化用斜体；状态区分用字重/边框/图案：**斜纹 = 处理中**（进度点、工作卡顶条、锚点标记），**双线框 = 待裁决/选中**（回看卡、委派卡、选中行、当前锚点）。动效归零后，用状态切换本身表达。控制台「灰度模拟」验证零信息损失。

### 3.2 排印

- 正文黑体（系统栈 PingFang SC，硬约束①），15px / 行高 1.75（黑体中文长文建议 ≥1.7，typography 调研）。
- **标题展示面（自由变量）的论证**：仅文档 h1 用衬线（Songti SC）。理由：h1 是作品的「铭牌」，衬线承载出版感并与界面黑体拉开层级；h2 以下保持黑体 650 字重 + 顶部 hairline，层级靠留白不靠字号差（Butterick「最小可见增量」）。仪器比喻上，h1 是表盘上的品牌铭文，其余刻度保持无衬线。
- tracking 随字号变化：11px 大写铭牌 `+0.08em`（eink 下 CJK 用 `+0.12em` 斜体）、13px UI 为 0、文档标题 -0.01em——不写死统一 letter-spacing（macOS SF 曲线的 HIG 依据）。
- 行宽滑块 480–1200px，默认 480px ≈ 32 汉字/行（CLReq 25–35）；右端近满宽只留必要页边距（Alex 裁决）。

### 3.3 签名链路的状态转换与微反馈

```
阅读 →（选中，浮层 150ms scale-in 贴选区）→ 创建
→ 锚点落入正文（点状下划线 + 4px 圆点，闪烁定位一次）
→ 工具栏出现「委派 N 个编辑点」
→ 委派卡：授权范围声明显式列出（授权先于修改大小，ADR 0005 §5）
→ 工作中：逐点状态点（排队/处理中/待回看），每点 950ms 推进，读数行同步 处理中 i/3
→ 完成：tone 横幅从顶部展开落下（方向=来自工作流），可点入回看，4.5s 退回余光
→ 回看：解释优先（你的问题→解释→词级内联 diff→影响与代价→跳正文），动词仅 接受/拒绝；进度读数 n/N 分母固定为本批全集，不随裁决收缩
→ 接受：正文段落整体淡入新文（just-in 高亮 900ms 渐隐），字数读数实时变化
→ 全部裁决：tone 横幅停留（带「归档」按钮，不自动消隐）→ 显式归档（横幅按钮或 ⌘K；归档是结束触发的显式动作，Rauno 分级触发）——锚点 150ms 淡出消失，surface 向右收回，toast 确认
```

tone 横幅 / toast / popup 均为 app 级元素（toolbar 之下、状态栏之上），不进正文滚动容器——滚动长文档时状态沟通不失联；横幅以 max-height 展开/收起，保留「从顶部落下」的方向感。

词级内联 diff 按中文字符/短语粒度（CJK 无空格分词），删除=灰字红划线、插入=青色加粗下划；eink 下删除=斜体划线、插入=双线下划。即席选中（非预制摩擦点）的编辑点走「仅解释、不修改正文」路径——这是 PRODUCT-CONCEPT §8 的合法结局，不是演示缺口。

### 3.4 导航重构（硬约束④）

左栏不再是文件管理器换皮，而是按 ADR 0005 对象模型组织的三段：

1. **Thread 卡**（意图空间一等对象）：目标 + 状态点 + 「N 开放 · M 待回看」等宽计数；
2. **阅读集合**：文件带角色 chip（主文档/参考/来源）——角色只属于当前 Thread；
3. **文件**：目录收折 + 行数读数右对齐（tabular），当前文件 = 左 2px 刻度 + bg-3 + 600 字重（eink = 双线框）。

右栏 Context Surface 默认宽度 0（硬约束③），delegate/working/review 三态从右滑入 220ms，归档后收回；⌘. 是三态手动覆盖（未碰=随 flow 自动，按过=以手动值为准），任何时候都不是空操作。命令面板 ⌘K 是一等交互位：全部主流程（创建/委派/接受/拒绝/跳转/归档/主题/面板）键盘可达，过滤即搜，禁用项灰显（eink 斜体）；「归档全部编辑点」只在全部裁决后可用。导航中非主文档的文件可真实切换（STUB_DOCS 一句话占位正文），签名流程只在主文档上演示。

## 四、取舍清单

| 取舍 | 选择 | 放弃 | 理由 |
| --- | --- | --- | --- |
| agent 进度表达 | 逐点状态点（排队/处理中/待回看） | spinner、进度条 | 状态点可逐格对应编辑点，spinner 只表达「在转」；仪器读数思维 |
| 委派确认的形态 | Context Surface 内卡片 | 居中 popup | popup 只给破坏性/冲突（calmtech 顶端）；委派是授权声明，不是告警 |
| 接受时的正文反馈 | 整段淡入 + 高亮渐隐 900ms | 逐词 FLIP 动画 | 词级重排在系统 webview 上成本/收益不划算；段落级 morph 已能传达「落定了」 |
| 完成提示 | 视觉横幅（tone 级） | WebAudio 提示音 | 演示环境声音是干扰；横幅自带「开始回看」入口，信息更完整 |
| 归档时机 | 全部裁决后显式动作（横幅按钮 / ⌘K） | 裁决完自动归档 | 归档让正文发生变化（锚点消失、surface 收回），属于破坏性一端的动作，按 Rauno 分级触发应等显式确认；未裁决完时该项禁用 |
| 即席编辑点的结局 | 仅解释、不改正文 | 编造伪 diff | 诚实：演示中无法生成真实改写；且「只得到解释」是产品定义的合法结局 |
| 文档内容双语 | 正文固定中文（fixture），UI 全量双语 | 正文也翻译 | 与 v1/v2 口径一致；英文 toggle 的职责是检查 chrome 布局弹性 |
| eink popup 遮罩 | 全透明（保留正文上下文） | 不透明白底 | 禁透明指禁半透明灰阶；全透明遮罩不产生灰阶且保住空间上下文 |
| 批注徽标 | 同一编号只钉第一处 | 每个元素都钉 | 重复元素（文件行）上的徽标是噪音，违背密度纪律 |

## 五、可实现性（Tauri + 系统 webview + CodeMirror 6）

- 无外部字体、无 WebGL、无动画库；全部 CSS transition/animation（transform/opacity/background-color），最长大于基线的只有 just-in 900ms 渐隐与 700ms 闪烁。
- `text-autospace:normal` 启用中西混排自动间距（初始值是 `no-autospace`；Chromium 153 实测 `normal` 产生 ≈1/4em 间距——同段宽度 104.52px vs 100.77px，`auto` 反而回退 no-autospace）/ `hanging-punctuation` 为渐进增强，老 webview 静默忽略。
- 锚点、词级 diff、状态点在 CodeMirror 6 里对应 decoration mark/widget 的直接映射；读数行与 surface 是普通 DOM。
- `prefers-reduced-motion` 下全部动效归零（与 eink 同一套约束路径）。
