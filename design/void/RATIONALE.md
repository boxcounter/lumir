# 「空」Void — 设计论证

走查入口：`design/void/index.html`（单文件，浏览器直开）。
URL 直达任意状态组合：`?theme=light|dark|eink & view=empty|full|long & step=read|anchor|delegate|working|review|conflict & nav=hidden|peek|open & surface=open & lang=zh|en & measure=480..1200 & annotate=on & gray=on`。

## 命题

**界面消失。默认状态下屏幕只有正文；agent 是全场唯一的色彩与动态元素。**

这是对「安静、清楚、有分寸」（PRODUCT-CONCEPT §4）最激进的诠释：不是把 chrome 做小、做淡、退两个色阶，而是让它在默认状态下不存在。导航、状态栏、计数器、tab——全部消隐。留下的只有文字。

agent 因此获得前所未有的在场感：当界面零色彩时，它出现的那一抹青（亮 `#2e6e63` / 暗 `#7cc3b1`）就是全部界面。它不是「一个面板里的状态图标」，而是房间里唯一亮着的东西。签名时刻：打开三秒后忘记界面的存在；agent 出现时，你不可能看不见它。

## 参照谱系

- **原研哉 / 無印良品「空」**：空不是无，是「能容纳任何意义的容器」。落地为：界面不提供未赢得注意力的元素，容器退到内容之后。
- **reMarkable / Daylight 的 distraction-free**：减法即全部排版的上位原则；eink 主题是本方向主场（纸的终态）。
- **HEY / 37signals 安静哲学**：单屏只做一件事；无 badge、无计数器；界面简单、底层复杂。
- **calmtech 余光原则（Amber Case）**：状态从余光进入焦点再退回余光。落地为三级唤出（见下）与 agent 状态灯（Status Light 级，popup 只给冲突）。
- **iA / Reichenstein 减法三分法**：更难用 = 更差；减少到本质 = 更好；**隐藏工作原理 = 永远更差**。这是本方向最大的风险，也是消隐逻辑设计的出发点（见下节）。
- **Tufte data-ink**：用户的文字是 data，一切 chrome 是可消退的 non-data-ink。

## 消隐逻辑的可预测性论证（回应 iA 三分法）

「界面自动消隐」最常犯的错误是智能隐藏：按滚动方向、停留时长、猜测意图来显隐——这就是「隐藏工作原理」，永远更差。本方向的消隐是**机械**的，规则全集如下，没有第四条：

1. **唤出入口固定且只有三个**：左缘 12px 热区（导航）、右缘 12px 热区（Context Surface，仅在 agent 在场时存在）、⌘K 命令面板（一切可达的兜底）。热区位置永不移动，不随滚动、不随内容、不随状态变化。
2. **关闭路径固定**：Esc 恒等于关闭最上层；点击正文/遮罩关闭浮层；鼠标移出导航即收回。
3. **动效恒定**：所有浮现/消隐均为 200ms ease-out 位移，无随机延迟、无速度感知。eink 下动效归零，即时切换。
4. **消隐 ≠ 隐藏状态**：agent 工作、待回看、冲突期间，右缘必然有一道状态灯（亮/暗为青色竖线，eink 为斜纹条），正文锚点必然带色。用户不需要记住「agent 是否在干活」——它在场就有标记。所有状态在需要时必须可达（命令面板列出全部动作），只是默认不占空间。

一句话：**消隐的是 chrome，不是信息；是默认态，不是可达性。**

## 导航重构（本方向核心考题）

考题：树如何唤出、如何不占空间又保持方位感。答案是 calmtech 余光→焦点光谱的三级深度：

- **0 级（隐藏）**：纯正文。零残留——不保留细线、不保留圆点。方位感不是靠「一直露一点」维持的，而是靠「随时用一个固定动作唤出」维持的（入口可预测即方位感）。
- **1 级（方位条/余光）**：鼠标触及左缘热区，浮现 208px 方位条：vault 名、当前文件路径、文件数与编辑点数。它**只回答「我在哪」，不给操作**——余光级的剂量就是这么多。
- **2 级（导航树/焦点）**：点击方位条 / 悬停 350ms / ⌘\\，完整树以 264px 覆盖层滑出。目录可折叠，当前文件用字重 + 左侧 2px 黑条标示（不用彩色，守住零色彩纪律）。

**关键决策：覆盖（overlay），不分栏。** v1/v2 的三栏 grid 里，导航出现会把正文推挤 240px——正文的位置随界面状态漂移，空间记忆被破坏。本方向所有临时层（导航、surface、浮层）都是覆盖：正文的行宽与位置在任何导航状态下恒定。消隐式导航不成立的一半原因都在推挤上；覆盖让「浮现」真正无代价。

树本身无图标：目录靠字重 500 + 展开符，文件常规体。图标是 chrome，chrome 消失。

## Context Surface：右栏默认隐藏的极值

ADR 0001/§13 的 Context Surface 在本方向推到极值：**它是按需浮现的 360px 临时覆盖层，随 agent 状态出现，用完即走**。普通阅读时右栏不存在（连边框都没有）；agent 工作时右缘出现状态灯 + 热区；进入回看时 surface 自动展开一次（有内容需要裁决，这是状态驱动的浮现，不是常驻面板）；归档后收回，右缘恢复为纯粹的页边。

回看卡片顺序严格遵循 ADR 0005 §5：你的问题 → 解释 → 词级修改 → 影响与代价 → 跳至正文。**裁决动词仅「接受 / 拒绝」两个**（Cursor 五动词是反例；VS Code Keep/Undo 证明两个够）。正文锚点处同步呈现词级内联 diff（评审界面就是编辑器本身，Zed 模式）；接受即 ins 融入正文、拒绝即恢复原文、归档即锚点从正文消失——编辑点以事务为家，事务关闭即从正文消失（ADR 0005 §4，视觉模式借 Google Docs suggestion 的 resolve-即消失，对象语义不借）。

## eink 主题（本方向主场）

约束集而非重新设计：纯黑（#000）纯白（#fff），**禁灰阶、无阴影、无透明、无动画**（CSS 层 `!important` 强制）。禁灰阶的直接后果是弱化与状态都不能用颜色深浅：

- **弱化 = italic**（控制台 dim 文案、meta 行、引用条）。
- **状态 = 字重 / 边框 / 图案**：斜纹 = agent 进行中（正文锚点下斜纹条、进度点斜纹、右缘状态灯整根斜纹条）；3px double 双线 = 待裁决 / 当前选中（锚点下划线、ins 下划线、active 按钮 outline）；加粗黑块 = 主操作。
- **agent 的在场**：色彩归零后，**图案即 agent**——斜纹是全场唯一图案元素，命题在 eink 下依然成立。
- 消隐无动画，即时切换（墨水屏刷新率约束）。
- 控制台「灰度模拟」toggle 是灰阶泄漏检查器：纯黑白主题在 `grayscale(1)` 滤镜下应无任何信息损失（走查截图 `eink-gray-review` 已验证）。

## 空态（第一打开是招牌）

几乎无物：屏幕中央一句细体 slogan（「阅读中的每一次卡顿，都是一次让文本变好的机会。」）、一个动作（打开一个目录）、底部一行快捷键提示。无 logo、无插画、无功能导览。它同时是命题的自证：产品还没有任何内容时，界面就已经消失了。

## 签名流程走查（真实可操作）

`view=full&step=read` 起：选中任意文字 → 创建浮层（自然语言意图）→ 正文虚线锚点 + 底部恒定位置的委派提示条 → ⌘⏎ 委派（浮层列出编辑点 + 授权范围文案）→ agent 工作（锚点呼吸 + 右缘状态灯 + surface 逐点进度）→ 逐点回看（解释优先、词级 diff、接受/拒绝）→ 全部裁决后归档 → 锚点从正文消失，正文归于安静。第三个预设编辑点（「熟悉你」有依据吗）是**只解释不修改**的类型——完成条件是人认为摩擦消解，不是文件改变（ADR 0005 §4）。

## 取舍清单

1. **0 级导航零残留**（连 1px 细线都不留）——换来真正的「空」，代价是首次发现性靠空态底部一行快捷键提示承担。赌的是：入口可预测（固定热区 + 固定键）即方位感，不需要常亮残骸。
2. **产品界面常态零色彩，链接也不着色**——wikilink 靠线型分工（实线 = 已创建、虚线 = 未创建）。这是命题的激进部分：agent 色彩的在场感以正文无色为代价。若裁决认为链接需要色彩，退回方案是链接用 agent 同族青（预算 1 色），但命题锐度下降。
3. **surface 覆盖而非分栏**——360px 覆盖层遮住正文右侧。宽行宽（1200）下会遮字；判断：回看是聚焦时刻，正文已被「跳至正文」联动定位，遮住可接受。
4. **委派提示条常驻底部中央**（有开放编辑点时）——这是唯一「出现即驻留」的元素，因为委派入口必须可预测；它不追踪滚动、不闪烁，hover 才加深。
5. **⌘K 命令面板作为可达性兜底**——面板本身是 chrome，但它是一切状态的备用入口，是「消隐 ≠ 隐藏」承诺的物质载体。
6. **不做**：字号设置（iA opinionated default：字号由阅读距离决定）、badge/计数器（HEY）、滚动感知隐藏（不可预测）、toast 通知以外的任何声音（桌面 webview demo 范围外）。
7. **非主文档为占位**——demo 只给主文档写了全文，树中其他文件打开显示占位说明，如实标注。

## 可实现性（Tauri + 系统 webview + CodeMirror 6）

无 WebGL、无动画库、无外部字体。全部动效为 CSS transition（transform/opacity）。消隐层是绝对定位覆盖层，CM6 编辑器无需让位。编辑点锚点对应 CM6 mark decoration；选区浮层对应 selection 事件 + 绝对定位 widget；词级 diff 为内联 decoration。`hanging-punctuation` / `text-autospace` 已写入但渐进增强，老 webview 静默忽略。
