思路：不是学工具，而是改进工作方式。

AI Coding 的基建、工作流规范

  1. 基建、流程、规范
    • .claude：Context engineering
    • PR：模板自动生成描述、AI 初审、Code Review Skills
  2. Review (Plan + Code) > Coding——从自动补全、我来设计结构，转向以 Review 为中心；除了 Agent 产出的质量，还要探究它为什么没达到预期
  3. 技能：Code Review、Agent 与 Hook、任务分解、TDD
  4. Pilot：忠旺重写 API；华南做 Slax Reader

从研发部的视角出发的 Tech Vision

  • 对各职能端的期望——从各端的年终总结中收集信息
  • PR：AI 编写描述，让 reviewer 快速了解概要；AI 做初审，降低 reviewer 的心智负担
  • 对忠旺——2026-01 和忠旺：全局统筹和主动同步；提高决策质量，通过写方案说清楚目标价值和取舍来实现
