# Heading 层级辨识度 · 对比稿（M224 过目包）

问题（Alex 原话）：「增加不同层级 heading（H1 H2 H3 ……）的辨识度，现在分不清哪些是 H2，哪些是 H3。」

基线：`docs/specs/design-tokens-v1.md` §字体——字号阶梯 24/19/16.5/15（doc-title/h1/h2/正文·h3），
字重 650 档覆盖 h1/h2/h3；H4–H6 阶梯无定义。现行实现 `src/preview/theme.ts:117-122`：
h3=15/650（与正文同字号）、h4/h5=15/600、h6=15/600 italic text-2。本目录的 `base` 稿即此现状对照。

  稿页右下角有稿/主题切换器（截图时已用 `?ui=0` 隐藏）。

## 三稿方向（一句话设计意图）

| 稿 | 意图 | H1–H6 规格（px/字重） |
|---|---|---|
| base | 现行对照：H2↔H3 只差 1.5px，H3–H5 与正文同字号 | 19/650 · 16.5/650 · 15/650 · 15/600 · 15/600 · 15/600it |
| A | **纯字号阶梯**：单变量，级差拉大 3/2/1/1/1，零装饰；代价是 H4 起 ≤ 正文靠字重收尾、阶梯新增 4 档 | 21/650 · 18/650 · 16/650 · 15/650 · 14/650 · 13/650 |
| B | **双族制**：H1–H4 字号×字重双轴递进；H5–H6 转入标签语汇（th/tg-label 同族：小字号+正字距+降明度），深档靠「族差异」而非级差 | 20/680 · 17.5/650 · 15.5/650 · 14.5/600 · 12.5/650+0.02em · 12.5/650+0.06em text-2 |
| C | **结构信号**：字号骨架不动，辨识度交给既有线语汇——H2 底线 hairline（th 手法）、H3 左侧 2px 竖杠（引用块手法，--text-3）；深档明度梯度 text→text-2→text-3；token 改动最小 | 19/650 · 16.5/650+底线 · 15/650+竖杠 · 14.5/650 · 13.5/600 text-2 · 12.5/600+0.04em text-3 |

## 各稿对 design-tokens-v1 的触动面（预判，定稿时落成正式 diff）

- **A**：字号阶梯新增 21/18/16/14 四档（13 已有）；字重阶梯不变；H4 低于正文需要一条新规则背书。
- **B**：字号新增 20/17.5/15.5/14.5 四档；**H1 20px 用 680 违反现行「680 只许 ≥21px」规则**——要么规则放宽到 ≥20px，要么 H1 改 21px 或降回 650，裁决点之一；深两档复用既有 12.5 档与 text-2。
- **C**：字号仅新增 14.5 一档（13.5/12.5 已有）；引入两条结构线规则（H2 底线、H3 竖杠），需写入「粗 hairline 三处不再新增」条款的例外清单——这是 C 的主要纪律成本。
