# 方向 B「编辑部·现代版」— 设计说明

原型：`index.html`（单文件自包含，无外部资源）。用法：`?screen=1|2|3` × `?theme=light|dark|eink`。目标视口 1280×900。

## 核心立场

文字就是界面，chrome 近乎消失。质感全部押在排版上：New York / Songti SC 衬线正文、648px 居中栏宽、1.72–1.78 行高、三级列表的悬挂缩进纪律。agent 没有常驻面板——Cmd-K 命令条（minibuffer）召唤，inline 修订裁决，提案沉淀为 overlay 队列里的一等对象。

## 三个屏的设计要点

**屏 1 · 纯编辑态。** 杂志式题区（kicker 短线 + 衬线大标题 + standfirst + 元信息发丝线），正文直接渲染真实 `2026-R&D-Strategy.md`。文件树是一栏 216px 的"文字栏"：无底色分隔、无文件夹图标、只有缩进与 7px 展开符，当前文件用 2px accent 竖条 + 6% 底色标出。标签页退化为文字 + 底部 2px 指示线。wikilink 渲染为 6% 底色小胶囊。

**屏 2 · agent 工作中。** 命令条以"余韵"态悬在顶部：内容降灰、边框降级、无阴影，右侧 spinner + "已受理"——它存在过，但不再要求注意力。进度下沉为底栏一条 2px accent 进度段 + 一行 11.5px 状态文（已读 X · 正在搜索 Y · 2/3 · esc 中断）。正文左 margin 外 40px 处有三态标记（✓ 已处理 / 脉动点 处理中 / 空心圈 排队），正文本身一字未动。

**屏 3 · 裁决时刻。** 三处修订内联织进正文：列表→段落改写（旧文红色删除线降灰 + 新段落 2px 绿左边条 + 淡绿底）、新增 wikilink（accent 虚线下划线 + 上标 +）、删节（删除线）。每处左 margin 有编号徽章，与命令条 overlay 队列一一对应。队列把 4 项提案（1 新建文档 + 3 本文修订）列为一等对象：图标、描述、`行号` 定位、当前项高亮、底部快捷键行。浮动审阅条在右下顺手位：2/4 计数 + 接受/驳回/全部接受。

## 六条原则如何体现

1. **内容即界面**：视口约 52% 是纯正文栏；所有层级（标题、列表、内链、代码片段）靠字体/字重/留白区分，无一处装饰。
2. **chrome 退后但不粗糙**：rail 34px 圆角按钮、文件树 25px 行高与省略号纪律、标签下划线指示、⌘K kbd 胶囊——每个控件都有对齐与状态设计。
3. **质感来自工艺**：全程无渐变、无插画；仅命令条/审阅条用一层 12px 模糊半径的浮动投影（eink 主题下投影归零）。
4. **色彩克制且语义化**：light 只有一个 accent（靛蓝 #3d55c9，交互/内链/agent 在场共用）；绿仅表示"新增"、红仅表示"删除"；eink 纯黑白灰，语义改由形状承载（删除线 / 虚线下划线 / 边条）。
5. **agent 可开可关**：屏 1 零 agent 痕迹（rail 上的 agent 图标也没有状态点）；屏 2/3 agent 的在场只通过命令条、底栏一行、margin 标记表达，正文始终主角。
6. **对话是输入不是档案**：指令说完即淡为"余韵"；产出沉淀为提案队列（可定位、可批量、行号回跳正文），不埋在对话流里。

## 三主题共享基因

同一套结构与排版 token，只换对比度分档：light 柔和（#fff 底 / #1d1d22 文）、dark 中性深灰（#17171a 底，accent 提亮为 #96a7f0）、eink 纯黑白灰、零彩色、零投影、发丝线全部换 1px 纯黑。屏 1 三主题完整打磨；屏 2/3 在 dark/eink 下结构不破（已逐张截图验证）。

## 我知道的妥协点（诚实清单）

- **文件树没有收起到只剩 rail。** 方向定位写的是"收敛成细窄 rail（或默认收起）"，我保留了 48px 图标 rail + 216px 文字树栏。理由：评审需要看到真实 PARA 三层结构，且 iA Writer/Ulysses 的实践证明安静的文字栏不构成噪音；但这确实稀释了"chrome 近乎消失"的激进程度。若裁决要更激进，把 `.tree` 默认隐藏即是完整方案 B+。
- **内容为 1280×900 裁过。** 真实文档 63 行装不满一屏也放不全：屏 1/2 略去「从公司的视角出发」小节与部分嵌套子项，个别长行截短（如 struck 旧文去掉"——是缺少业务上下文，还是缺少背景"）；屏 3 的被删旧文与屏 1 可见文本保持逐字一致。省略号分隔符（···）兼作"此处有省略"的诚实标记。
- **字体依赖系统**：New York 在非 macOS 上落到 Charter/Georgia；中文统一落 Songti SC。截图在 Chrome headless 完成，WKWebView 下字重渲染会略饱满。
- **修订色语义借了通行惯例**：删除红 #c24a38 与旧 editorial 暗红 accent 色相接近，但此处它只是 tracked-changes 的语义色，不再是品牌 accent——若裁决认为仍有旧风格联想，可换为中性灰删除线。
- **快捷键（⌘⏎ 接受 / ⌘A 全部接受等）是示意**，未与实际 keymap 对齐；agent 状态文案（"2/3"）是虚构的合理值。
- **标签栏只有一个半标签**（一激活一非激活），多标签溢出、脏标记等状态未呈现。
