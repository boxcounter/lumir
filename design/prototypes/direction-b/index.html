工作重心正从「我来写」移向「我来审」：过去是自动补全、自行设计结构、自行决定设计模式；今后是 Review over Coding。审的不只是 Agent 的 Plan 与 Code 的质量，还要追问它为什么没有达到预期——缺的是业务上下文，还是背景信息。
