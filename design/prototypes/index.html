  • harness-selector-merge — harness 模型选择器合并：双 chip（model + Thinking）合并为一个三维度选择器 chip（M371 原型，M373 按 Alex 裁决定稿：chip = model · effort 双读数、只截 model 名、两个 hover hint——决策见目录内 NOTES.md）
  • harness-composer-image-paste — harness composer 贴图 UX（M424 原型）：图片卡与摘录卡同视觉族；单图/多图/图文交错、发送沉淀、能力闸拦截（toast 人话错误 + 卡片错误态）、缩略图占位态；场景截图在目录内 screenshots/
  • subagents-tasks — Subagents / Tasks 用户可见面（M578 原型，对应 change add-harness-subagents design §19）：任务区（并行 / 等待批准 / 后台 / 完成态）、批准卡透传、后台完成通知、按模型用量、子代理清单、关停空态；页面内置控制面板（场景 / 主题 / 面板状态），截图用 ?panel=0
  • semantic-selection-proto-oct24 — 语义选中 · D4 覆盖范围可视化对比（M665 原型，对应 change semantic-selection-markdown-oct23 的 D4 裁决点）：每类语法一个剖面，「拖选中（未松手）/ 松手·现状 / 松手·D1=A」三态并排，纳入系与不纳入系分组；源码条标出选区范围，琥珀虚线标「上屏但未选中」，反事实取证标「选区含永不上屏字符」；页面内置控制面板（主题 / 语法组 / 状态列 / 链接处置 / 反事实 / 定位剖面），深链 query 与 ?panel=0 口径同 subagents-tasks
  • keybindings-lookup-oct24 — 键位速查（M696 原型，对应 change improve-keybindings-lookup-oct24 的节点 1）：每命令一行、多键合并、来由移详情；文本查询 + 按键捕获、分组 / 折叠、scope 筛选、未绑定与空态、Help 菜单入口（无加速键）；页面内置控制面板（主题 / 场景 / 查询 / 作用域 / 捕获 / 分组 / 详情 / 入口），深链 query 与 ?panel=0 口径同 subagents-tasks；内容全为合成 fixture
  • model-automation-settings-oct24 — 模型接入与自动化设置面板（M716 原型，M730 按 Alex 评审重做自动化节；对应 change add-model-automation-settings-oct24）：完整 provider 管理——provider 列表 / 添加（id + 预设）/ 编辑 / 删除（当前使用项、命名引用、未保存草稿的替代目标与保护）、重复 id 与空清单、预设只读、Base URL 密钥目的地警示、模型清单逐行编辑（id / effort / vision / window）；四个全局自动化开关，会话命名与图片命名的目标内联在各自开关行、provider / 模型可编辑（默认跟随当前 provider，关闭时禁用但保留）、图片模型标 vision 资格、会话失效覆盖模型回落而图片保留并跳过、选择旁仅一行实际生效说明（含来源与时机，无独立摘要框）；单页两节、无 TAB。页面内置控制面板（十六场景 × 三主题 × provider × 添加 / 删除 / 高级区），截图用 ?panel=0
