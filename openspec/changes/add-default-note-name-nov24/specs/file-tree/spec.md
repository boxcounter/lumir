## ADDED Requirements

### Requirement: 新建文件的默认名预填

当配置键 `editor.prefill_note_name` 为 `true` 时，内联新建文件（目录行菜单 / vault 根级菜单 /
空 vault 的新建入口，同属「目录下新建」条的同一条链路）的输入框 SHALL 预填当前界面语言的
人类可读默认名：zh 为 `未命名笔记`，en 为 `Untitled note`。默认名 SHALL 只含主文件名、不含
`.md`；提交时仍按既有默认扩展名规则补 `.md`（`withDefaultFileExtension` 那一处）。

预填之后输入框 SHALL 全选该默认名：用户直接键入即整段替换，不需要先删。`Enter` SHALL 接受
当前名称并按既有创建链路落盘、自动打开，随后焦点按「新建文件后焦点落在正文首行」条交给新
文档正文；`Escape` SHALL 按既有内联编辑取消语义撤销本次新建（不落盘）；`Tab` MUST NOT 被
本特性接管，沿用浏览器既有的焦点移动与随之而来的失焦取消。

预填名与同级既有条目撞名时，SHALL 自动递增为 `未命名笔记 2` / `Untitled note 2`、`3`… 直到
不撞名；判据 SHALL 对**最终落盘名**（补 `.md` 之后）作出，与输入时的撞名预检同源。该自动
递增 SHALL NOT 扩展到用户自己输入的名称：自定义名称仍走既有撞名校验，撞名时留在编辑态并
回显原因，MUST NOT 静默改名。

`editor.prefill_note_name` 为 `false` 或键缺席时，新建文件的输入框 SHALL 与 change 之前逐字
相同：空值 + 既有占位（`未命名`），不预选任何文本。本特性 SHALL 只作用于 `create-file` 的
内联编辑；内联重命名、新建子目录、wikilink 一键创建、未命名内存文档等其它创建 / 命名链路
MUST NOT 受影响。

默认名的语言 SHALL 取自界面语言的既有唯一真源（`<html lang>` / `t()`），切换语言后下一次
新建 SHALL 使用新语言的默认名；MUST NOT 为该文案另立语言判定。

#### Scenario: 开关关闭时行为不变

- **WHEN** `editor.prefill_note_name` 为 `false` 或键缺席，用户在目录行菜单选「新建文件」
- **THEN** 内联输入框为空、显示既有占位「未命名」，没有任何文本被选中；用户输入的名字按既有
  默认扩展名与撞名规则落盘，与 change 之前逐字相同

#### Scenario: 开关开启时预填并全选

- **WHEN** `editor.prefill_note_name` 为 `true`，界面语言为 zh，用户在目录行菜单选「新建文件」
- **THEN** 输入框值为 `未命名笔记` 且整段处于选中态（不含 `.md`）；用户直接键入 `想法` 时
  输入框变为 `想法`（不是 `未命名笔记想法`），按 `Enter` 后磁盘出现 `想法.md`

#### Scenario: 接受默认名并聚焦正文

- **WHEN** 开关开启，用户对预填的 `未命名笔记` 直接按 `Enter`
- **THEN** 磁盘出现空文件 `<父目录>/未命名笔记.md`，新文档自动打开；焦点按既有创建链落到
  编辑器正文（`document.activeElement` 是 `.cm-content`），随后键入的字符进入该文档

#### Scenario: Escape 取消预填的新建

- **WHEN** 开关开启，输入框已预填默认名，用户按 `Escape`
- **THEN** 内联编辑退出，临时行撤掉；磁盘逐字节不变，不产生任何新文件或目录

#### Scenario: 默认名撞名时自动编号

- **WHEN** 同级已有 `未命名笔记.md` 与 `未命名笔记 2.md`，开关开启时再次新建文件
- **THEN** 输入框预填 `未命名笔记 3` 并全选；接受后磁盘出现 `未命名笔记 3.md`，既有两条
  逐字节不变

#### Scenario: 用户自定义撞名不被静默改名

- **WHEN** 开关开启，同级已有 `想法.md`，用户把预填名改成 `想法` 并按 `Enter`
- **THEN** 创建被拒绝，编辑态保留、行内回显撞名原因；既有 `想法.md` 逐字节不变；MUST NOT
  自动改成 `想法 2`

#### Scenario: 新建子目录与重命名不受影响

- **WHEN** 开关开启，用户新建子目录或对既有条目发起重命名
- **THEN** 两处输入框都不预填默认名：子目录为空 + 既有占位，重命名预填既有条目名（其既有
  口径；本特性 MUST NOT 给重命名新增全选）；本条特性 MUST NOT 改变它们

#### Scenario: 默认名跟随界面语言

- **WHEN** 开关开启，界面语言为 en（`<html lang>` 为 `en`），用户新建文件
- **THEN** 输入框预填 `Untitled note` 并全选；切回 zh 后下一次新建预填 `未命名笔记`
