## ADDED Requirements

### Requirement: 光标与焦点切换时的行盒稳定

同一文档在同一主题下，光标、选区或焦点进入 / 离开标准 Markdown 链接与裸列表 marker 行时，装饰重建 MUST NOT 改变该行的 `.cm-line` 高度、可见正文文本的字形高度或基线位置，也 MUST NOT 改变后续行的 top。链接尾标与列表 marker 的颜色、字号、符号、宽度及既有交互语义 SHALL 保留；稳定性 MUST 由这些装饰自身的静态排版几何保证，MUST NOT 依赖运行时测量补偿或按光标状态选择另一套行高。

链接源码显露与裸 marker 的 widget 切换仍 SHALL 按既有判据发生，其横向排版可随可见源码变化。其他构造的合法源码显露换行仍按既有有界重排合同处理；本 requirement MUST NOT 把所有 Markdown 构造统一成同一行高，也 MUST NOT 禁止内容编辑或合法换行造成的必要高度变化。

#### Scenario: 链接尾标不撑高渲染态行盒

- **GIVEN** 文档含标准 Markdown 链接及后续正文，光标初始在链接外
- **WHEN** 光标反复移入 / 移出链接，并在链接内失焦后重新聚焦
- **THEN** 链接整条源码按既有合同显露 / 恢复，尾标在渲染态保留既有符号与链接激活路径
- **AND** 两态下行高、正文基线与后续行 top 的差异均不超过 0.5px，文档字节不变

#### Scenario: 裸 marker 切换 widget 不推动后续行

- **GIVEN** 段落后的裸列表 marker 行及后续正文，光标初始在该行外
- **WHEN** 在 light 或 eink 主题下反复移入 / 移出该行，并在该行失焦后重新聚焦
- **THEN** 编辑态仍显示既有列表 marker widget，离开后恢复字面源码
- **AND** 两态下行高与后续行 top 的差异均不超过 0.5px；有正文可测时基线同样稳定，文档字节不变

#### Scenario: 合法源码显露与内容换行不被误禁

- **GIVEN** 文档含标题、强调或行内公式等既有源码显露构造，以及会因内容长度合法换行的正文
- **WHEN** 光标触及这些构造或编辑内容导致合法换行
- **THEN** 既有显露行为与本行有界重排照常发生，后续行只随前序行实际高度变化位移
- **AND** 本 requirement 不对这些构造施加全局固定行高
