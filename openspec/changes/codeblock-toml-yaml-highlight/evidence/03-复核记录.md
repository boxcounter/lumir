## 6. `meta` / `punctuation` 的产出语言普查（「方案 B 是跨语言改动」这条断言的依据）

命门：yaml 的结构符号（`-`、`:`、`,`、`{}[]`）返回 `meta`，而 `meta` 不在 `TOKEN_GROUPS` 的任何组里。
若按「方案 B」给它补色，就必须在 `TOKEN_GROUPS` 新增角色，而该 token 名并不是 yaml 独有。

命令与输出（在 `node_modules/@codemirror/legacy-modes/mode/` 下逐个 mode 文件跑）：

```
$ for f in javascript python go rust clike ruby shell toml yaml css xml swift lua sql; do
    n=$(grep -oE "[\"'](meta|punctuation)[\"']" $f.js | wc -l | tr -d ' ')
    b=$(grep -oE "[\"']bracket[\"']" $f.js | wc -l | tr -d ' ')
    echo "$f meta/punct=$n bracket=$b"; done
javascript meta/punct=4 bracket=0
python meta/punct=7 bracket=0
go meta/punct=0 bracket=0
rust meta/punct=1 bracket=0
clike meta/punct=8 bracket=0
ruby meta/punct=0 bracket=0
shell meta/punct=1 bracket=0
toml meta/punct=0 bracket=2
yaml meta/punct=6 bracket=0
css meta/punct=4 bracket=0
xml meta/punct=4 bracket=0
swift meta/punct=3 bracket=0
lua meta/punct=0 bracket=0
sql meta/punct=1 bracket=1
```

读数：21 门收录语言里 **10 门**（javascript / python / rust / clike / shell / yaml / css / xml / swift / sql）
会产出 `meta` 或 `punctuation` 类 token；`bracket` 另有 toml 与 sql 产出（`bracket` 同样不在任何分组里）。
`lua` / `ruby` / `go` 三种一个都不产出。

**口径说明（避免假阳性）**：必须用带引号的 token 名匹配。用 `grep -c "meta"` 会对 `lua.js` 报 4 次命中，
但那全是 `getmetatable` / `setmetatable` 这类函数名的子串，不是 token——按 token 名匹配后 lua 是 0。

据此：给 `meta` 加角色会**同时改掉 10 门语言的观感**（并触发大面积视觉基线重建），
这不是「修一处错色」的边界内动作，故本 change 把方案 B 列为待 Alex 裁决的选项而非默认项。
