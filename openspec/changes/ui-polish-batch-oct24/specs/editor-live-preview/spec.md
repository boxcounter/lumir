# editor-live-preview 增量规格

> 起草注记（非规格正文）：本 delta 一条 ADDED，不动既有的「表格放大全屏查看」/「代码块放大全屏
> 查看」两条 requirement（它们只定义内容来源、关闭路径与只读语义，未规定内容在浮层内的水平对齐）。
> 新条款只补「窄内容居中」这一条呈现口径，并与既有「宽内容 / 折行档行为不变」的条款对齐。

## ADDED Requirements

### Requirement: 全屏浮层窄内容的水平居中

代码块全屏遮罩的内容容器在其自然宽**小于**浮层可用宽时 SHALL 水平居中（内容盒相对面板内边距盒的
左右余量相等），MUST NOT 贴左；自然宽不小于可用宽时行为 MUST NOT 改变（宽度钳到可用宽、左余量为 0，
超长行仍由壳横向滚动到达）。折行口径（`editor.code_block_wrap = true`，内容宽 100%）MUST NOT 因居中
改变行宽或引入横向滚动。表格全屏由「面板壳按内容收缩 + 遮罩 flex 居中」承担同一视觉结果，本条款
MUST NOT 改变其面板几何。实现 SHALL 只取既有布局手段（`margin-inline: auto` 一类），MUST NOT 新增
token、内边距或第二套宽度规则。

#### Scenario: 窄代码块居中

- **WHEN** 打开一个自然宽明显窄于浮层可用宽的代码块全屏遮罩（例如缩进代码块的两行短文本）
- **THEN** 内容盒两侧余量相等（差 ≤1px），内容的底板 / 圆角 / 字体形态不变

#### Scenario: 宽代码块与折行档行为不变

- **WHEN** 打开一个含超长行的代码块（不折行档）；随后在折行档打开同一块
- **THEN** 前者内容宽度不缩、左余量为 0、壳横向可滚（`scrollWidth > clientWidth`）；后者内容按壳宽折行、无横向滚动
