## 步骤（在真实 app 里做，建议直接用你自己的 vault）

1. **打开**：双击文档里一张已渲染出来的图片 → 出现全屏遮罩、图片居中；大图完整可见（不出现滚动条），
   小图按原尺寸不放大。同时看一眼关闭前文档区与 masthead 的几何没有被推动。
2. **三条关闭路径**（每次关闭后再双击打开，逐条走）：`Esc` / 点击图片以外的遮罩区域 / 在图片上再次双击。
   三条都应立刻关掉遮罩。
3. **焦点归还**：任一条关闭路径之后，直接按 `⌃D`（Emacs 删除前向字符）——应当真的删掉光标处一个字符；
   若没反应，说明焦点没回到编辑器（按 `⌘Z` 撤销）。
4. **占位没有打开路径**：双击「加载中…」「图片无法显示：…」「图片读取失败：…」「附件未找到」这几类
   占位块 → 一次都不应出现遮罩，也不应出现任何提示。

## WKWebView 特有的观察点（chromium 里看不到，只能真机看）

- 双击图片时**是否误触发文本选择**（图片周围的文字被选中一块）或**页面放大手势**（图片被放大后无法还原）。
  预期：都没有——双击本身只 `preventDefault`，不产生选区、不改变文档。
- 遮罩打开期间输入 `⌃D` / `⌃K` / `⌃A` 与 `Tab`：文档不应发生任何变化，焦点应留在遮罩内。
- 遮罩打开期间按 `⌘F` / `⌘⇧O` / `⌘O` 这类全局命令：新面板抢走焦点后，遮罩应自己退场（不会留下
  「背景里还开着一个模态层」的状态）。
