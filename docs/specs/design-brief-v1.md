# Lumir Design Brief v1

> 状态：已由 Alex 裁决确认（2026-09-24）。用途：UI 重设计阶段的气质定义与裁决依据。原型阶段产出的方案以本 brief 为准绳评估。

## 气质定义

**看起来像一件打磨过的消费品，用起来是一个键盘驱动的专业文本工作台。**

Lumir 不是「开发者工具的开发者工具」，是「重度文本工作者的日常器物」——像 Things 那样每个细节被推敲过，但服务对象是每天几小时阅读和写作的人。

## 六条设计原则

1. **内容即界面。** 正文排版承担主要质感。界面 80% 是文本，排版好 = 产品好。
2. **chrome 退后，但不粗糙。** 元素少而精：每个出现的控件都必须打磨到位——对齐、间距、圆角、hover 反馈、过渡动效。消费品质感和简陋的区别全在这里。
3. **质感来自工艺，不来自装饰。** 不做渐变堆砌、阴影卡片、装饰性图标和插画。质感 = 字体、留白、对齐纪律、克制的动效。
4. **色彩克制且每色有语义。** 保留 modus 主题的纪律（颜色少、对比达标、语义化），但色相选择走现代柔和路线，不要终端味。
5. **agent 可开可关。** 不在场时零痕迹；在场时是一个打磨过的 pane（Zed 的克制结构 + Things 的表面质感），不是聊天气泡。
6. **对话是输入，不是档案。** agent 可以有 chat 式交互表面（下指令、提问、讨论、迭代草稿）；但 agent 的产出与待办——改了哪些文件、提交了什么提案、等你定什么——必须沉淀为独立的一等对象，可排队、可回看、可批量处理，不埋在对话时间流里。

## 参考权重

| 权重 | 参照 | 取什么 |
|---|---|---|
| 主参照 | Things、Ulysses、iA Writer | 整体气质、留白、次级界面品质感 |
| 纪律参照 | Emacs modus 主题 | 对比度纪律、色彩语义化（不取色相） |
| 结构参照 | Zed | agent pane 的结构与克制（不取它的粗粝表面） |
| 弱参照 | Linear | 键盘驱动的速度感 |
| 反例 | VS Code、Notion、Cursor、Obsidian 默认主题 | IDE 密度、卡片化、agent 喧宾夺主、设置爆炸 |

## 已识别的张力（原型阶段验证）

**消费品质感 vs eink 主题。** 柔和现代风格易滑向低对比灰蓝层次，而 eink 要求高对比零灰度。解法假设：三主题共享同一套结构和排版基因，对比度分档——light/dark 走柔和，eink 对比拉满。原型阶段需三主题各出一张验证。

## 裁决记录

- **2026-09-24 · 骨架**：选定方向 C「驾驶舱」（常驻 agent 栏：上 chat 下 Inbox 提案队列；选中提案中间栏切换为完整审阅视图）。理由：agent harness 是产品核心演进方向，队列 + 专门审阅视图对多任务、大提案的承载力最强。
- **表皮**：迭代中。第一轴：正文衬线 vs 无衬线 → **2026-09-24 裁决：无衬线**（serif 变体保留在 `?body=serif` 备查）。
- **2026-09-24 · 最终样式**：Alex 检查定稿图（主界面 + 内容类型 + 浮层 + callout × 三主题，见 `design/prototypes/final-review/`），结论「挺喜欢」，无必须改项。本次实现范围 = 方向 C 骨架（无 agent 的三栏布局，右栏预留 dock 位）+ 无衬线表皮，三主题。屏 2/3（agent 假设）、composer 变体推迟到 agent 特性立项时再设计。
- **2026-09-24 · 节点 1 提案评审通过**（change `restyle-ui-tokens-v1`）：D1 = 15px；D2 = 本 change 内收敛 callout 13 类 → 五族语义色（tokens v1.2 映射表，abstract/todo 两个存疑类型 Alex 裁决**按现方案**）；D3 = `[ui] theme` 配置（默认 light、重启生效）。浮层 elevation（v1.1 `--shadow-raise`/`--scrim`）渲染检查通过。

## 留给原型阶段的分叉

- **agent 交互形态的主次**：panel 派 / minibuffer 派 / inline 派，渲成可选方案后裁决。
- **chat 与裁决对象的关系**：提案从对话里「长出来」变成卡片，还是对话与提案队列并列。
- **密度档位**：Things 式低密度在工作台场景是否太奢侈，用真实 vault 内容验证。
- **字体策略**：UI 用系统字体（SF Pro）基本无争议；正文衬线 vs 高品质无衬线是气质分歧最大的一格，原型里两个都做。
